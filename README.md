# Сайт-резюме Нюры Батруковой

Статичный сайт: HTML, CSS и немного JavaScript, без сборки. Выложен на GitHub Pages:
https://nikiuiux.github.io/batrukova-cv/

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Все тексты и структура: первый лист, листы разделов, фото с мероприятий, карточка-меню |
| `css/style.css` | Оформление: цвета и шрифты в начале файла (`:root`), дальше размеры и положение листов в дефолтном кадре |
| `js/drag.js` | Перетаскивание, раскадровка (куда едут листы по клику в меню), мобильная версия со свайпом |
| `img/photo.jpg` | Фото на первом листе |
| `img/events/` | Фото с мероприятий на листе Conferences |
| `files/Niura_Batrukova_CV.pdf` | PDF резюме для кнопки Download CV |

## Как поменять текст

1. Открой `index.html` на GitHub и нажми карандаш (Edit).
2. Найди нужный текст через Cmd+F и исправь его. Теги вокруг текста (`<p>`, `<h1>`, `<li>`) не трогай.
3. Нажми **Commit changes**. Через 1–2 минуты изменения появятся на сайте.

Кавычки в английском тексте типографские: “ ”. Между числом и словом и после коротких слов (a, the, of, to) можно ставить неразрывный пробел `&nbsp;`, чтобы слово не оставалось одно в конце строки.

## Как заменить фото

Загрузи новое фото в папку `img` с именем `photo.jpg` (Add file → Upload files) с заменой старого. Файл открывается по прямой ссылке, поэтому фото само по себе не должно показывать лицо, если это важно.

## Как обновить PDF резюме

Загрузи новый файл в папку `files` с тем же именем `Niura_Batrukova_CV.pdf` (Add file → Upload files) с заменой старого. Ссылку в `index.html` менять не нужно.

## Как поменять цвета и шрифты

В начале `css/style.css` блок `:root`: там переменные `--bg` (фон), `--paper` (листы), `--card` (карточка-меню) и шрифты `--font-display`, `--font-text`. Меняешь значение в одном месте, оно применяется везде.

## Где поменять раскадровку

В начале блока «Storyboard» в `js/drag.js` таблицы с координатами из Figma (px во фрейме 1440 × 900): `HOME` дефолтное положение, `CENTER` открытый лист, `AWAY` левая стопка, `CARD` меню справа. Третье число в каждой строке это поворот в градусах, как в Figma.

## Как устроен масштаб

Вся композиция масштабируется от ширины листа: внутри размеры в `cqw` (1cqw = 1% ширины листа). Пересчёт из Figma: размер в px ÷ 5,25 = значение в cqw (лист First шириной 525 px). На экране 1440 × 900 сайт совпадает с фреймом один в один.

## Если правки не видны на сайте

Браузер держит старые файлы в кэше. После изменения `css/style.css` или `js/drag.js` увеличь номер версии в `index.html`: `style.css?v=2` → `style.css?v=3` (и так же для `drag.js?v=`). Тогда у всех посетителей загрузятся свежие файлы. Для себя можно просто обновить страницу через Cmd + Shift + R.

## Шрифты

- Medeo Sans лежит в папке `fonts`.
- ITC Bodoni Seventytwo подключается из Adobe Fonts строкой `use.typekit.net/mov4rsg.css` в `index.html` (веб-проект «Batrukova CV» в аккаунте Adobe). Файлы этого шрифта на сайт класть нельзя, так требует лицензия Adobe. Если подписка закончится, шрифт пропадёт, и сайт покажет запасной Bodoni.

## Аналитика

GoatCounter, статистика на https://batrukova.goatcounter.com (вход своим e-mail и паролем). Счётчик подключён в конце `index.html`.
Кроме просмотров считаются события: `open-work`, `open-teaching` и другие (какие разделы открывали в меню), `download-cv`, `contact-email`, `contact-telegram`, `contact-instagram`. Они видны в списке страниц как отдельные строки.
